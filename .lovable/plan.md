# Personal AI Assistant foundation

## Build
- Create a warm paper/charcoal visual system with deep teal accents, semantic warning, danger, and success colors.
- Load Fraunces, IBM Plex Sans, and IBM Plex Mono, assigning monospace styling to system-facing labels and placeholder signals.
- Build a responsive shell with desktop sidebar, compact mobile navigation, branding, mode switching, theme control, and a visual-only logout action.
- Add distinct empty states for Chat and Tasks & Notes without implementing either feature.
- Add restrained entrance, hover, and control animations with reduced-motion support.

## Interactions
- Switch between Chat and Tasks & Notes using local state.
- Persist the selected light or dark theme across reloads, defaulting to the device preference.
- Collapse mobile navigation after selecting a mode.

## Validation
- Confirm the page builds cleanly.
- Check the shell, navigation, and theme behavior at desktop and mobile sizes.
